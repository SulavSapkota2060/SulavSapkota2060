## Featured projects

| Project | What it does | Stack |
|---|---|---|
| **[Wildfire Retardant Drops](https://github.com/SulavSapkota2060/wildfire-retardant-drop-ml)** | A geospatial ML pipeline that predicts which side of an aerial fire-retardant drop is the protected side. 91.5% accuracy in fire-grouped cross-validation, and 89.6% on later drops labeled by different people. | Python · GeoPandas · Rasterio · XGBoost · scikit-learn |
| **[Himalayan Quake Atlas](https://github.com/SulavSapkota2060/quake-atlas)** ([live](https://sulavsapkota2060.github.io/quake-atlas/)) | A Python and SQLite pipeline plus an interactive dashboard over 10,125 USGS earthquakes. It shows how the completeness cutoff swings the b-value from 0.79 to 1.27. | Python · SQLite · pandas · Chart.js · Leaflet |
| **[Rumor Mill](https://github.com/SulavSapkota2060/rumor-mill-gossip-sim)** | A C++20 discrete-event gossip simulator. Across 180 runs on a 1,000-node graph, more fanout buys speed (10.6 → 1.8) but not a lower message cost. | C++20 · Python · pandas · Make |
